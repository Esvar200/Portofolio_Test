Speech AI · for Google

Live Accent Neutralization

2 send-to-end latency

Problem
Convert Indian English speech to British English live, without losing the speaker's identity, prosody or meaning.
Approach
An end-to-end audio pipeline in Python with the Gemini API and Google ADK, backed by a multi-metric evaluation framework and a timing drift detector that aligns word-level timestamps to flag delayed and dropped words.
Result
2-second end-to-end latency, evaluated on 900+ audio samples.
  1. Indian English audio
  2. Gemini API + ADK pipeline
  3. British English audio
  4. Evaluation: WER, speaker similarity, audio quality, semantics

  • Evaluation

Agentic AI · for Google

Multi-Agent Retail Location Strategy

200×faster: 5 hours → 90 seconds

Problem
Site-feasibility analysis for a retail location took about 5 hours of manual research.
Approach
A 6-agent system that pulls live competitor density, reviews and location signals within 10 km through Google Maps MCP, the Geocoding API and Google Search, and mines low-rated competitor reviews for pain-point themes.
Result
A report in 90 seconds, with an explainable 0-100 viability score and a rationale for every factor.
  1. Target location
  2. Orchestrator + Research, Competitor, Gap Analysis, Strategy and Report agents
  3. Scored report
  • Google ADK
  • MCP
  • Google Maps
  • Geocoding API
  • Multi-agent

NL2SQL · HCLTech internal

AI-Powered Business Assistant

65% → 85%accuracy on a 190-question test set

Problem
Non-technical business users needed answers from an 18-table SQL database in plain English.
Approach
Query rewriting and object-relation mapping that link business concepts to the right tables, plus an automated harness that compares generated-SQL results with ground truth for all 190 questions.
Result
Accuracy up from 65% to 85%, used every day by 50+ business users through a Microsoft Teams bot.
  1. Question in Teams
  2. Query rewriting
  3. Object-relation mapping
  4. SQL on 18 tables
  5. Answer
